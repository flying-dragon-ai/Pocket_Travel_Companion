# 口袋旅行搭子 PD 商业计划书

## 1. 项目概述

### 1.1 项目名称

口袋旅行搭子

### 1.2 项目定位

口袋旅行搭子是一款面向 18~35 岁年轻人的情绪疗愈型周末微旅行规划助手。产品通过情绪问答、AI 路线生成、NFC 实体玩偶唤起、打卡与豆子激励、分享传播等能力，把用户模糊的心情状态转化为可执行、有陪伴感的短途旅行路线。

### 1.3 一句话介绍

让年轻人不用熬夜做攻略，也能根据当下心情快速拥有一条适合自己的周末微旅行路线。

### 1.4 产品愿景

从“查攻略”变成“被理解地出发”，让短途旅行不只是地点推荐，而是情绪恢复、生活探索和城市陪伴的新入口。

---

## 2. 背景与机会

### 2.1 用户背景

当代年轻人工作、学习和社交压力较高，周末常有出门散心、约会、放松、独处、轻社交等需求。但实际行动前，用户往往需要在小红书、抖音、地图、点评平台之间反复切换，筛选景点、餐饮、交通、时间和预算，决策成本较高。

### 2.2 市场痛点

1. **攻略成本高**：用户需要跨平台搜索和整理信息，容易因为麻烦而放弃出行。
2. **推荐同质化严重**：多数平台基于热度推荐，缺少对用户情绪、关系场景和出行状态的理解。
3. **短途旅行缺少陪伴感**：用户不是只需要路线，也需要被鼓励、被理解和被陪伴。
4. **出行行为难以持续**：一次出行结束后，缺少激励、沉淀和再次使用的理由。
5. **内容平台攻略难以直接执行**：自媒体内容种草能力强，但路线结构、交通顺序、营业信息和时间安排需要二次整理。

### 2.3 商业机会

周末微旅行、本地生活、情绪消费、AI 助手和文旅 IP 周边正在形成交叉机会。口袋旅行搭子可以以 AI 路线规划为核心工具，以情绪陪伴为差异化体验，以 NFC 玩偶和豆子体系增强品牌记忆和用户留存，逐步延展至本地生活交易、城市文旅合作和 IP 衍生品。

---

## 3. 目标用户与核心场景

### 3.1 目标用户

| 用户群体 | 特征 | 核心需求 |
|---|---|---|
| 周末散心年轻人 | 18~35 岁，学习或工作压力较大 | 快速获得低压力、可执行的放松路线 |
| 情绪疗愈用户 | 失恋、焦虑、疲惫、想独处 | 希望路线能匹配情绪，而不是只看热门 |
| 约会/社交用户 | 暧昧期、情侣、朋友聚会、轻社交 | 需要有氛围、有话题、容易执行的路线 |
| 内容平台重度用户 | 经常刷小红书/抖音种草 | 希望把碎片内容快速转化为完整行程 |
| 城市探索用户 | 喜欢小众地点、拍照、咖啡、展览 | 希望发现符合个人偏好的城市路线 |

### 3.2 核心使用场景

1. **周五晚上不知道周末去哪**：用户填写心情和时间，系统生成半日或一日路线。
2. **工作压力大想放空**：系统推荐安静、自然、低强度路线。
3. **失恋或情绪低落想被治愈**：系统避开高刺激或情侣密集场景，推荐疗愈路线。
4. **暧昧期或情侣约会**：系统推荐互动体验、氛围餐厅和夜景散步点。
5. **刷到自媒体攻略但懒得整理**：用户粘贴链接，系统解析景点并生成可执行路线。
6. **线下触碰 NFC 玩偶唤起小程序**：通过实体玩偶强化陪伴感和品牌记忆。

## 4. 问题陈述

年轻人并不缺“想去的地方”，真正缺的是把心情、时间、预算、关系场景和城市信息整合成一条可执行路线的能力。传统旅游产品更偏目的地和热门榜单，内容平台更偏种草和灵感，小程序工具则往往缺少情绪理解和持续激励。

口袋旅行搭子要解决的问题是：

> 如何让用户在低决策成本下，根据当下情绪快速获得一条有温度、可执行、可分享、可持续激励的周末微旅行路线？

---

## 5. 解决方案

### 5.1 产品闭环

```text
探索灵感
  ↓
情绪问答 / 快速调整心情
  ↓
AI 生成路线 / 导入自媒体链接
  ↓
用户采纳路线并消耗豆子
  ↓
线下出行、打卡、评论
  ↓
获得豆子奖励
  ↓
生成分享图并传播
  ↓
再次进入探索与路线生成
```

### 5.2 核心功能

| 模块 | 功能说明 | 用户价值 |
|---|---|---|
| 情绪地图 | 通过 7 题问答收集社交身份、情绪状态、节奏、兴趣等信息 | 让推荐从“热门”转向“适合我” |
| AI 路线生成 | 根据情绪、时间、预算、景点偏好生成路线 | 降低攻略和决策成本 |
| 自媒体链接导入 | 粘贴小红书、抖音等链接并转化为路线 | 把种草内容变成可执行行程 |
| 路线预览与采纳 | 用户先看路线，确认后扣除豆子生成个人路线 | 降低试错成本，增强付费/扣费合理性 |
| 景点打卡 | GPS 校验后上传照片和干货标签 | 增强真实参与感和内容沉淀 |
| 豆子系统 | 路线生成消耗豆子，打卡/评论/更新情绪获得豆子 | 构建持续使用激励 |
| 分享图 | 自动生成路线或景点分享图 | 促进裂变传播 |
| NFC 玩偶 | 触碰实体玩偶唤起小程序路径页 | 增强仪式感、品牌感和线下入口 |

### 5.3 差异化亮点

1. **情绪优先，而非地点优先**：先理解用户状态，再规划路线。
2. **路线可执行，而非单点推荐**：输出完整行程、顺序、耗时和建议。
3. **AI + 本地生活结合**：将大模型、RAG、地图 POI 和用户画像结合。
4. **虚拟积分驱动留存**：通过豆子形成生成、打卡、评论、分享的循环。
5. **实体玩偶增强品牌**：NFC 玩偶让产品从纯线上工具扩展到线下陪伴 IP。

## 6. AI 与技术实现

### 6.1 技术架构

| 层级 | 技术选型 | 说明 |
|---|---|---|
| 前端 | Vue 3、TypeScript、uni-app、Pinia、SCSS | 面向微信小程序实现页面、状态管理和交互 |
| 后端 | Node.js、Koa、RESTful API、JWT | 提供登录、路线、景点、豆子、分享等接口 |
| 数据库 | PostgreSQL | 存储用户、路线、景点、评论、豆子流水等数据 |
| 测试 | Vitest | 覆盖前端业务规则、后端模型和工具函数 |
| AI 能力 | 大模型 Prompt、RAG、地图 POI、距离矩阵 | 用于个性化路线生成和内容理解 |
| 外部能力 | 微信授权、地图服务、小程序码、NFC URL Scheme | 支撑真实小程序体验和线下触达 |

### 6.2 AI 路线生成流程

```text
用户输入 / 情绪问答结果
  ↓
结构化用户画像
  ↓
读取用户偏好：城市、时间、预算、同行关系、节奏、兴趣
  ↓
检索旅行知识库 / 景点信息 / 用户评价
  ↓
调用地图 POI 与距离矩阵
  ↓
组装 Prompt 给大模型
  ↓
生成候选路线
  ↓
校验时间、距离、豆子扣费与异常情况
  ↓
返回路线名称、简介、途径点、推荐理由、打卡建议
```

### 6.3 核心 Prompt 示例

```text
你是一个情绪疗愈型周末旅行规划助手。

请根据用户的情绪状态、出发城市、可用时间、预算、同行关系和偏好，生成一条适合短途微旅行的路线。

要求：
1. 路线必须优先匹配用户当前情绪，而不是只推荐热门景点。
2. 每个地点都需要说明推荐理由，并解释它如何匹配用户情绪。
3. 路线强度不能过高，需要适合周末放松。
4. 需要给出预计耗时、交通建议、预算范围和打卡建议。
5. 如果用户情绪低落或压力大，避免过度嘈杂、排队严重或强社交场景。
6. 输出语气温暖、简洁、有陪伴感。

用户信息：
- 当前情绪：{{mood}}
- 出发城市：{{city}}
- 可用时间：{{duration}}
- 预算：{{budget}}
- 同行关系：{{companion}}
- 旅行节奏：{{pace}}
- 主题兴趣：{{interests}}
- 必去地点：{{must_go_places}}

请输出：
1. 路线名称
2. 路线简介
3. 行程安排
4. 每个地点的情绪匹配理由
5. 交通与耗时建议
6. 打卡建议
7. 注意事项
```

### 6.4 数据落库设计方向

核心数据可围绕以下实体落库：

| 数据实体 | 关键字段 | 用途 |
|---|---|---|
| 用户 User | id、openid、nickname、avatar、beanBalance | 登录、资产、身份识别 |
| 情绪画像 MoodProfile | userId、socialIdentity、moods、pace、interests、goals、updatedAt | 个性化推荐与路线生成 |
| 路线 Route | id、userId、title、summary、status、source、costBeans | 保存用户生成或采纳的路线 |
| 路线点 RouteSpot | routeId、spotId、order、duration、transportInfo、reason | 表达完整行程顺序 |
| 景点 Spot | name、address、lat、lng、tags、openingHours、ticketInfo | 地点基础信息 |
| 打卡 Checkin | userId、spotId、routeId、photos、tags、content、createdAt | UGC 内容与豆子奖励 |
| 评论 Comment | userId、spotId、content、rating、likeCount | 景点评价和同好流 |
| 豆子流水 BeanTransaction | userId、type、amount、reason、relatedId、createdAt | 记录消耗和奖励 |
| 分享 Share | userId、targetType、targetId、shareCode、posterUrl | 分享图和小程序码回查 |

## 7. 商业模式

### 7.1 初期模式

初期以用户增长和体验验证为主，商业化轻量介入：

1. **免费基础体验**：用户可浏览推荐、完成情绪问答、查看部分路线灵感。
2. **豆子消耗机制**：生成路线、导入链接等高价值能力消耗豆子。
3. **任务激励获取豆子**：打卡、评论、更新情绪、分享获得豆子。

### 7.2 中长期商业化方向

| 商业化方式 | 说明 | 适用阶段 |
|---|---|---|
| 本地商家合作 | 咖啡店、展览、市集、剧场等进入推荐路线 | 用户规模稳定后 |
| 城市文旅合作 | 与城市文旅局、景区、街区共创主题路线 | 有样板城市后 |
| NFC 玩偶售卖 | 城市限定玩偶、主题搭子、联名 IP | 品牌形象成熟后 |
| 会员权益 | 高级路线、无限生成、专属主题、更多画像维度 | 留存稳定后 |
| 内容种草转化 | 连接小红书/抖音种草内容和线下消费 | 链接导入成熟后 |
| 数据洞察服务 | 为文旅方提供匿名化趋势洞察 | 数据规模足够且合规后 |

### 7.3 收入结构假设

1. **B2C 收入**：NFC 玩偶、会员订阅、高级路线权益。
2. **B2B 收入**：城市文旅合作、商家推广、主题路线共创。
3. **交易佣金**：未来接入门票、活动、餐饮预约后，可获得转化佣金。

## 8. 市场与竞争分析

### 8.1 竞品类型

| 类型 | 代表能力 | 局限 |
|---|---|---|
| 内容平台 | 小红书、抖音种草内容丰富 | 内容碎片化，用户仍需自行整理路线 |
| 地图平台 | POI、导航、距离准确 | 缺少情绪理解和旅行主题编排 |
| OTA 平台 | 酒店、门票、长途旅行交易成熟 | 更偏目的地交易，不适合轻量周末微旅行 |
| AI 工具 | 可生成路线文本 | 缺少小程序落地、打卡激励和本地数据闭环 |

### 8.2 竞争优势

1. **场景更聚焦**：专注周末微旅行，而不是泛旅游。
2. **体验更情绪化**：围绕心情、关系和状态推荐路线。
3. **闭环更完整**：从生成路线到打卡、评论、分享和激励。
4. **线上线下结合**：NFC 玩偶提供差异化入口和 IP 延展。
5. **技术可扩展**：AI、RAG、地图服务和用户画像可持续优化推荐质量。

## 9. 运营策略

### 9.1 冷启动策略

1. **官方内容预埋**：为首批城市导入 TOP 50 热门景点和高质量带图评论。
2. **主题路线模板**：预置失恋疗愈、暧昧升温、姐妹出街、上岸自习、社交破冰等路线。
3. **校园与年轻人社群试点**：从大学城、创意园区、商圈周边进行测试。
4. **分享图传播**：鼓励用户在朋友圈、微信群、小红书发布路线成果。
5. **城市限定 NFC 玩偶**：以低成本周边建立品牌记忆和线下触点。

### 9.2 增长策略

| 增长手段 | 机制 |
|---|---|
| 分享得豆子 | 用户分享路线或打卡图获得豆子 |
| 邀请好友 | 好友首次使用后双方获得奖励 |
| 主题活动 | 周末疗愈路线、城市隐藏路线挑战 |
| UGC 沉淀 | 用户打卡和评论成为后续推荐素材 |
| 本地商家联动 | 商家提供优惠或限定打卡任务 |

### 9.3 留存策略

1. 每周豆子自动发放，提醒用户周末出行。
2. 超过 7 天未更新情绪时，引导用户更新心情。
3. 历史足迹沉淀用户旅行记忆。
4. 打卡、评论、点赞通知增强反馈。
5. 根据历史偏好持续优化推荐。

## 13. 风险与应对

| 风险 | 表现 | 应对策略 |
|---|---|---|
| AI 推荐不准确 | 路线不符合实际距离、营业时间或用户情绪 | 接入地图数据、规则校验、用户反馈闭环 |
| 冷启动内容不足 | 初期路线和评论较少 | 官方预置内容、主题模板、城市样板运营 |
| 用户留存不足 | 生成一次后不再回来 | 豆子体系、每周补给、情绪更新提醒、足迹沉淀 |
| 商业化过早影响体验 | 推荐被认为是广告 | 商业内容标注，优先保证路线质量和用户匹配度 |
| 数据合规风险 | 涉及位置、情绪和用户行为数据 | 明确授权、最小化采集、隐私协议、数据脱敏 |
| 外部服务依赖 | 地图、微信、大模型接口不稳定 | fallback 机制、失败不扣豆、服务降级 |

## 15. 总结

口袋旅行搭子以“情绪疗愈型周末微旅行”为切入点，解决年轻人出行前攻略成本高、推荐不够个性化、行动缺少激励的问题。产品通过 AI 路线生成、情绪画像、豆子系统、打卡分享和 NFC 玩偶形成差异化闭环，既具备工具价值，也具备内容、社区、本地生活和 IP 衍生的商业延展空间。

短期目标是完成 MVP 和小范围用户验证，中期目标是提升路线推荐准确性和用户留存，长期目标是成为年轻人周末城市探索和情绪恢复的入口型产品。
